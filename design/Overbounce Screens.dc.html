SCREENSDecided menu screens — updated against the repo

Repo sync: the .pk3 loader screen is gone — loader.ts was deleted. Course select now mounts the bundled kit itself and carries its own drop/browse section, so there's no detour before seeing courses. The title menu is trimmed to two entries — "Learn the movement" and "Load .pk3 assets" are both gone as destinations. The self-damage/arsenal practice toggles from the earlier mockup were never built into course select — only Physics and Camera are real pickers there (a fourth camera option, FPV, exists in code and is added below). Cheating is a URL param (?selfdamage=0) read at run time, not a course-select UI control.

The remaining screens, as decided. Shell is shared with Overbounce Settings: 224px left rail on #0e0e12, 60px header, #15151b cards on #101014, 1px #22222c seams, 22/28/18 body padding, 14px gaps, footer commit bar. Type is Barlow Condensed for headings and numerals, JetBrains Mono for data. Dim text is #8a8a96; #4a4a54 means unavailable and nothing else. Physics and camera are chosen per course on this screen, with AUTO resolving to the map's own declaration. The HUD lives in Overbounce HUD spec, the post-run screens in Overbounce Results.
